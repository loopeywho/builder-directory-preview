Aider

Coding agentsresearchedchecked 2026-10-24

Edit a local Git repository with a chosen model

Who it suits
Developers comfortable with a terminal and code review
Verdict
A researched first pick when explicit file selection and model choice matter more than a visual IDE.
Trade-off
Model quality and token spend vary; terminal operation is less approachable than a browser builder. Not benchmarked against Cursor or Claude Code.
Privacy and access
Files added to chat are visible to the configured model provider; local CLI does not automatically mean private inference. Review commits and restrict credentials.
Pricing and limits
Checked 2026-10-24: usage docs confirm chosen external or local models and warn that added files cost more tokens. Provider or local inference costs apply; no fixed service price or observed spend established.

VibeiDE

Coding agentsnew/unrankedchecked 2026-10-27

Queue and review several local coding agents without losing task history

Who it suits
Builders already using Claude Code, Codex or OpenCode across projects
Verdict
New, unranked candidate when terminal juggling becomes a problem; start with one read-only task before enabling parallel writes. A queue is not filesystem isolation.
Trade-off
Paid orchestration on top of separate provider costs. Select independent worktrees yourself. Maker reports full validation on macOS; Windows support has narrower validation and Linux is experimental. Not installed or benchmarked here.
Privacy and access

Pricing and limits
