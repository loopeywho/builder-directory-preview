Aider

Coding agents · researched · checked 2026-10-24

Edit a local Git repository with a chosen model

Who it suits

Developers comfortable with a terminal and code review

Verdict

A researched first pick when explicit file selection and model choice matter more than a visual IDE.

Trade-off

Model quality and token spend vary; terminal operation is less approachable than a browser builder. Not benchmarked against Cursor or Claude Code.

Privacy and access

Files added to chat are visible to the configured model provider; local CLI does not automatically mean private inference. Review commits and restrict credentials.

Pricing and limits

Checked 2026-10-24: usage docs confirm chosen external or local models and warn that added files cost more tokens. Provider or local inference costs apply; no fixed service price or observed spend established.

Bolt.new

App builders · researched · checked 2026-10-24

Prototype a JavaScript web app in the browser

Who it suits

Vibe coders who want to start without installing a local toolchain

Verdict

A researched first pick for browser-first scaffolding; move security and deployment review outside the prompting loop.

Trade-off

WebContainer and JavaScript ecosystem constraints; prompt iterations consume tokens. The repository README is not proof of current hosted-service parity.

Privacy and access

Inspect project visibility and hosted-service data terms before adding private source or credentials. An agent can alter the filesystem and run packages.

Pricing and limits

Checked 2026-10-24: Free $0/month with 1M tokens/month, daily limits, public/private projects and Bolt branding. Page displays Pro $18/month equivalent ($216 billed annually), 10M tokens/month with rollover. This is an annual-billing display, not a verified monthly checkout quote; verify promotion and hosting limits before purchase.

Supabase

Databases · researched · checked 2026-10-24

Build customer accounts with relational application data

Who it suits

Small SaaS builders prepared to design access policies

Verdict

A researched starting choice when Postgres, authentication and storage belong together.

Trade-off

You still own row-level security, backups and usage controls. Knowledge Base is public beta; migration guides are not an automated migration service or a guarantee against data loss.

Privacy and access

Test isolation with two separate accounts; do not place service-role credentials in browser code. Review hosting region and retention requirements.

Pricing and limits

Checked 2026-10-24: Free $0/month, 500 MB database, 2 active projects, paused after one week of inactivity. Pro from $25/month; additional projects from $10/month and usage overages apply. Guides do not remove hosting or migration costs.

Claude Code

Coding agents · researched · checked 2026-10-26

Make a bounded repository change while tracking coding-agent usage

Who it suits

Terminal-oriented builders who can review diffs and run project tests

Verdict

A researched candidate for a scoped edit/test/review loop. Use /usage to inspect consumption; do not confuse an API cost estimate with a subscription invoice.

Trade-off

Gateway retries and permission fixes are vendor-reported, not independently tested. Monitor availability now extends to Bedrock, Vertex and Foundry, with long foreground sleeps blocked there too; verify scripts and denial behavior on your own provider before upgrading production.

Privacy and access

Review repository and tool permissions, exclude secrets, and inspect provider data terms before sending private source. Human review remains necessary.

Pricing and limits

Checked 2026-10-26 in official costs docs: API use is token-billed; Pro/Max subscribers have included usage subject to plan limits. /usage session dollars estimate API list-price consumption, not subscription billing. No fixed subscription price verified in this run; consult linked plan pricing before buying.
